# seqattn-core v0.3.0-alpha.4

Date: 2026-08-28

This alpha separates optional multi-GPU execution from the single-GPU core and
adds explicit MiniMax-H3 materialized and QKV-recompute runner contracts.

Packaging changes:

- `seqattn-core` no longer ships or exports `MultiGpu*` schedulers, runners, or
  statistics;
- the separate `seqattn-multigpu` distribution contains static and dynamic
  scheduling plus the materialized-QKV multi-GPU H3 runner;
- both distributions use version `0.3.0a4`, and the plugin requires exactly
  `seqattn-core[dit]==0.3.0a4`;
- `seqattn_core.features` discovers optional plugins through entry points and
  reports an explicit feature-not-installed error when no provider exists.

DiT API changes:

- `H3MaterializedRunner` uses sequence-sized pinned host Q/K/V;
- `H3RecomputeRunner` uses two pinned hidden buffers and regenerates Q and K/V
  from an immutable source buffer for each block;
- `H3MaterializedProjection`, `H3RecomputeProjection`, and `H3BlockOps` keep
  weight and consumer leases separate, and the attention epilogue receives the
  residual hidden host tensor explicitly.
