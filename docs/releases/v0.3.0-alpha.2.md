# seqattn-core v0.3.0-alpha.2

Date: 2026-08-24

This Alpha refresh keeps the core-only package and replaces the README's mixed
historical performance section with the latest trusted validation data.

Documentation changes:

- redraw the README figures directly from the final A30 and RTX 5090
  host-memory roofline observation files;
- retain only the August 24, 2026 experiments in the README performance
  section;
- compare the RTX 5090 `membind=5` and `interleave=5,7` policies relative to
  their distinct independently predicted Q knees;
- remove stale workspace, projection, and model-integration benchmark claims;
- keep one link to the external ComfyUI integration.

Packaging changes:

- exclude `seqattn_core.benchmarking` from the release wheel;
- remove benchmark console entry points and benchmark-only package extras;
- retain benchmark source, requirements, experiment data, reports, and figures
  in the tagged repository for reproducibility.

The runtime implementation and public `seqattn_core` API are unchanged from
`v0.3.0-alpha.1`.
