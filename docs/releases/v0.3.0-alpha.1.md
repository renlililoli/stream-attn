# seqattn-core v0.3.0-alpha.1

Date: 2026-08-24

This is the first minimum feature-complete Alpha release. The distribution is
core-only: public imports use `seqattn_core`, and the former `seqattn`
compatibility facade is not shipped.

Included execution paths:

- contiguous host-memory streaming with bounded HBM;
- fixed-host-budget paged memory and NVMe execution;
- projection-attention-output pipelining;
- built-in Triton plus explicit FlashAttention 2/3/4 streaming backends;
- A30 and RTX 5090 calibration, roofline analysis, and benchmark reports.

Validation:

- 87 tests passed on the RTX 5090 CUDA environment;
- the two CUDA timing-race regression cases passed five consecutive rounds;
- Ruff 0.9.10 checks passed;
- the wheel contains only `seqattn_core` and its subpackages.

Versioning convention:

- `0.3.0.devN`: development snapshot, normally untagged;
- `0.3.0aN` / `v0.3.0-alpha.N`: minimum feature-complete Alpha release;
- `0.3.0` / `v0.3.0`: stable release after API stabilization.
