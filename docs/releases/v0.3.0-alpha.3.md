# seqattn-core v0.3.0-alpha.3

Date: 2026-08-25

This Alpha release merges the MiniMax-H3 DiT block runtime into the main
`seqattn-core` package. The public API now includes `H3DiTRunner`,
`H3BlockOps`, `H3SequenceMeta`, and `load_h3_tile_config`.

Packaging changes:

- add the `dit` install extra for consumers that require the Triton-backed H3
  block runtime;
- keep the DiT implementation inside the independent Apache-2.0 core package,
  without any ComfyUI imports or vendored copies;
- set the default H3 QKV and MLP tile sizes to 4,096 tokens while retaining
  TOML overrides through `SEQATTN_CONFIG`.

The ComfyUI integration is expected to depend on `seqattn-core[dit]`, adapt
ComfyUI model operations to `H3BlockOps`, and keep framework-specific weight
loading and cleanup outside this package.
